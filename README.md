<h1>Football Analysis Web Project</h1>

This project will combine a tactical board with machine learning to produce a website that allows the user to test
tactical setups, with freely customisable attacking and defensive formations, and choice of players

This project will build upon previously made python packages to extract player and team data to be used in analysis.

## The vision:

### Matchup Explanation Tool
- Players can be moved anywhere on the pitch according to the user's liking.
- Data will be combined with my knowledge of the game to estimate strengths and weaknesses and produce a probable result.
- Any outstanding mismatches or points of interest would be identified and relayed back to the user.

### New dataset tools
- This project will contain wide amount and range of datasets that will be built upon to create functions that return datasets that containing: 
1. percentile data
2. position based statistics
3. a better overview of overall match data (including pass/shot distances etc.)

    <br>Users will be able to view analytical graphs using data from these datasets. At this moment in time, the amount of sites with percentile rankings and position based comparison analytics are reduced but not gone, as they do still exist on sites like sofascore, but easy-to-use sites that give the user freedom to compare on in depth stats are hard to find.
